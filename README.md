# ATLANTIS v18 — Cloudflare Workers 版

6つの都市が地続きになった **8 km × 6 km** の3Dサバイバルゲームです。街並みは約8.2万棟の建物からなり、200 m四方の1,200区画を現在地の周りから読み込みます。

## 遊び方

1. 道路に落ちている30冊の本のうち、10冊を拾います。徒歩で近づくと自動で拾います。
2. 東京タワーの広場にある赤い鳥居をくぐると、追跡者と巨人が成仏します。14秒の間に広場の外へ退避してください。
3. 巨大ジェット8基で広場ごと700 mまで上昇します。上昇を終えると、地盤の下から展開した砲台が追尾ミサイル「ゲルニカ」を10秒ごとに発射します。攻撃フェーズを10分間生き延びるとクリアです。
4. 耐久力は4目盛りです。徒歩で直撃を受けると2目盛り減り、車内では車が大破して1目盛り減ります。

徒歩はWASD、スマホは左のスティックで移動します。Shiftまたは「走る」でダッシュし、画面をドラッグして見回します。車は近くにある駐車車両にVまたは「車に乗る」で乗れます。W・Sで加速・後退、A・Dで操舵、Shiftでブレーキです。停車すると降車できます。

コンパスには次の目標（いちばん近い本、10冊集めた後は鳥居）の方向と距離が表示されます。PCでは E で地下鉄などの操作、F で全画面、M で消音、Esc で設定を開きます。設定の「マウスで見回す」をオンにすると、クリックでカーソルを固定してドラッグせずに見回せます。ゲームパッド（標準配置）にも対応しています。左スティックで移動・操舵、右スティックで視点、Aで走る・ブレーキ、Bで乗降、Xで地下鉄などの操作、スタートで設定です。

地下鉄は駅入口を見つけて「地下鉄へ」「列車を呼ぶ」「列車に乗る」と進みます。約15 kmの環状線は7つの駅を結びます。空港の展望デッキでは旅客機の離陸を見られます。道路トンネルも車や徒歩で通れます。

## 街と建物

集合住宅の階高は3.77〜4.05 mです。集合住宅と高層ビルは間口と奥行きを広げ、高さと面積に応じた敷地と基礎を持ちます。高層ビルのロビーの床や壁には当たり判定があります。東京タワーは従来モデルの高さ・幅・奥行きの5倍です。

漆喰の塗り直し、石造外壁の修復、タイルや金属板への張り替えなどで、外観と経年劣化が変わります。180棟の集合住宅では、低層階の窓越しに家具やカーテンが見えます。間取りと内装の配色は棟と窓ごとに生成されます。

幹線道路、中道、小道、砂利道、砂道を整備しました。生成する敷地は、前面から道路へ続く通路を確保できる場所を使います。各都市にはコンビニ、ショッピングセンター、駐車場、公園、建設中の高層ビルがあります。100人の歩行者が街路を巡回します。

屋外は常に昼です。レンガ、石材、コンクリート、木、金属、砂利など29種類の素材に、実寸に合わせた模様と凹凸があります。水面は岸の高さに沿って生成し、遠くの海と空は視線の方向に合わせて描画します。

区画は近い順に読み込みます。描画品質の「自動」は動作速度に合わせて解像度を調整します。Cloudflare版では徒歩・車の移動、列車の呼び出しと乗降、追跡・本の回収・ミサイルの飛行とダメージをサーバーで処理します。

## グラフィック

描画はWebGL 2のリニアHDRパイプラインです。素材や模型のダウンロードを増やさず、すべてシェーダーと実行時の生成で描きます。

- **空と大気**: レイリー散乱・ミー散乱・オゾンを積分した物理ベースの空を、太陽や霞が変わるたびにGPUで表に焼きます。積雲の層は地上に動く雲の影を落とし、遠景は大気遠近法で霞みます。
- **ライティング**: GGXの物理ベース反射、空と地面・建物からの照り返し、2段のカスケードシャドウ（接地点ほど鋭く、離れるほど柔らかい影）、画面空間アンビエントオクルージョン。
- **ポストプロセス**: テンポラルアンチエイリアス、ブルーム、ACESトーンマッピング、色調補正、太陽のグレア、フィルムグレイン。
- **建物と内装**: 窓ごとに奥行きのある部屋をレイで描きます。床・天井・壁・家具・カーテンやブラインド、オフィスの照明、窓から差し込む日だまりが視線に合わせて見えます。ガラスはフレネル反射で空と街並みを映します。
- **人物と車**: 歩行者、追跡者、巨人は符号付き距離関数から生成した滑らかな人体メッシュで、歩き・走りの骨格アニメーションをGPUで計算します。顔、髪、服の縫い目や襟、靴まで描き分けます。車はクリアコート塗装、ガラス、回転するアルミホイールを持つ専用メッシュです。メッシュはWeb Workerで起動時に生成します。
- **自然**: 樹冠は葉の塊ごとに凹凸と隙間を持ち、逆光で透けて風に揺れます。水面と海は波と空の反射、太陽のきらめきを描きます。上空では鳥の群れが旋回し、地面に影を落とします。
- **動きと光**: 爆発や発射時のエンジンの光が周囲を照らします。運転中の車はブレーキランプ・バックランプが点き、前輪が切れ、加減速やカーブで車体が沈み込みます。近くの歩行者はプレイヤーの方へ顔を向けて道を空け、まばたきもします。一人称視点でも自分の影が地面に映ります。
- **カメラ**: 明るさに目が慣れるような自動露出、速く移動したときのモーションブラー、速度に応じて広がる視野角、爆発や巨人の足音による画面の揺れ。ハイライトのちらつきは法線の変化から抑えます。

効果音もすべてWeb Audioで合成しています。街のざわめきと風、足音、車のエンジンとロードノイズ、ゲルニカの飛来音、距離に応じて遅れて届く爆発音、本を拾う音などが鳴ります。

設定では視野角、上下の視点操作の反転、モーションブラー、画面の揺れ、音量、フレームレート表示も切り替えられます。「描画品質」は次のとおりです。**自動**はフレーム時間に合わせて解像度を下げ、スマートフォンではアンビエントオクルージョンを省きます。**高精細**はすべての効果を高い解像度で描きます。**軽量**は影・時間方向のアンチエイリアス・室内表現・雲の影を省き、FXAAで仕上げます。浮動小数点の描画先を使えない端末では8ビットの描画先に自動で切り替え、WebGL 2自体を使えない場合は従来どおりソフトウェア描画になります。

## 画像生成テクスチャ

`gpt-image-2.5-sunburst`（正方形1:1、モデルが受け付ける最大の解像度、品質 medium）で、1枚の画像に3×3の9種類のテクスチャを生成してゲームに組み込めます。`tools/texture-catalog.json` に10枚分・90種類（これまで手続き生成だけだった素材36種類と、ビルの外観・屋根・街路など54種類）のプロンプトと、使う素材・実寸・色の扱いを定義しています。

```sh
python3 .claude/skills/gpt-image-textures/generate.py --dry-run
OPENAI_API_KEY=... python3 .claude/skills/gpt-image-textures/generate.py
```

生成した画像は各マスを切り出して継ぎ目のないタイルにし、`dist/materials/generated/` にWebPのアトラスと `manifest.json` として書き出します。ゲームは起動時にこれを読み込み、素材ごとに最大8種類のテクスチャから建物ごとに1つを選んで貼ります（ビル全体で同じものを使います）。生成前や読み込めない端末では、これまでの手続き生成の質感のまま動きます。APIキーはリポジトリに保存しないでください。手順の詳細は `.claude/skills/gpt-image-textures/SKILL.md` にあります。

## 自分のCloudflareにデプロイする

1. このリポジトリをクローンするか、配布用ZIPを展開し、`package.json` があるフォルダを開きます。Node.js 22または24のLTS版を使用してください。
2. 次のコマンドを実行し、ブラウザの認証画面でデプロイ先のCloudflareアカウントを選択します。

```sh
npm ci
npm run build
npx wrangler login
npm run deploy
```

3. Wranglerが表示する `https://…workers.dev` を開きます。画面右上に **Cloudflare 接続済み** と表示されれば、サーバー処理が有効です。初めてWorkersを使うアカウントでは、案内に沿って `workers.dev` サブドメインを設定します。

`npm run build` はワールド区画、衝突・遮蔽データ、素材を生成します。配布用ZIPにはこれらの生成済みデータが入っています。

Worker名は `wrangler.toml` の `name` で変更できます。すでに同名の別プロジェクトがある場合は、初回デプロイ前に変更してください。SQLite Durable Objectは初回デプロイ時のマイグレーションで用意されます。データベースやストレージの個別作成、ゲーム用APIキーの発行は不要です。

`/api/health` を開くと `service: "atlantis"`、`world: "atlas-13"`、`protocol: 3` を確認できます。Cloudflare側の設定と利用枠は各アカウントに適用されます。 [Workersの制限](https://developers.cloudflare.com/workers/platform/limits/) · [Durable Objectsの利用枠](https://developers.cloudflare.com/durable-objects/platform/limits/)

## 処理の分担

| 処理 | 実行場所 |
| --- | --- |
| 加速・減速、歩行・走行、衝突、重力、斜面と水域、橋、地区境界 | Durable Object。最大60 Hz相当の刻みで再計算し、サーバーの経過時間で入力時間を制限 |
| 追跡、遮蔽物、本と鳥居、東京タワーの離陸、ミサイル、車両のダメージ | Durable Object。確定結果をWebSocketで返送 |
| 現在地、耐久力、本の回収状況、ミッションの一時保存 | セッションごとのSQLite |
| 3D区画の配信 | Workers Static Assets。周辺区画を端末が取得し、移動に合わせて先読み |
| 3D映像、タッチ入力、応答を待つ間の移動予測、照明や噴射炎・煙の描画 | ブラウザ。移動予測はサーバーの確定結果で補正 |

移動中は操作を約100 msごとにまとめて送信します。停止中も敵やミサイルが動くよう、プレイ画面を開いている間は約100 msごとに進行を同期します。タイトルや設定を開くと、プレイ時間が一時停止します。

クラウド版は1ブラウザにつき1つの匿名セッションです。同じサイトとブラウザで再訪するとゲームが復元されます。プレビュー版の端末内データとは保存先が異なります。新しいタブでゲームを開くと、先に開いていたタブの操作接続が閉じます。

## ローカル確認とマップの再生成

```sh
npm ci
npm run build
npm run dev:cloud
```

テストは開発サーバーと別のターミナルで実行できます。

```sh
npm test
npm run test:cloud
```

`dev:cloud` はWranglerのローカル実行です。通常は `http://localhost:8787` で確認できます。クラウド統合テストはバンドルをdry runで生成し、ローカルのworkerdとテスト専用SQLiteで接続、移動、本の回収、再起動後の復元を確認します。

街路やマップを編集するときは `tools/layout.mjs`、`tools/build-world.mjs`、`dist/geography.js` を参照してください。地図データを公開済みの版から変更する場合は、地図のキャッシュを切り替えるため `WORLD_VERSION` と `dist/_headers` の区画パスを合わせて更新し、`npm run build:world` を実行してからデプロイします。

素材の模様は `tools/build-materials.mjs` で編集できます。変更後は `npm run build:materials` で配信用データを生成します。

## GitHub Pagesで公開する

GitHub Pagesの公開元が「ブランチ（`main` の直下）」のままだと、ゲーム本体の `dist/` もワールドデータも公開されず、README.mdがトップページとして表示されます。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
2. **Actions** タブで **Deploy to GitHub Pages** を実行します。以後は `main` に反映するたびに `.github/workflows/pages.yml` がワールドデータを生成し、テストを通してから `dist/` を公開します。

GitHub Pages版はサーバー処理のない「ブラウザ版」として動き、進行状況はブラウザに保存されます。なお、GitHubのリポジトリ画面でファイル一覧の下にREADME.mdが表示されるのはGitHubの標準の動作です。
