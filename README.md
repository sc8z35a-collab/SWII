# ATLANTIS v19 — Cloudflare Workers 版

6つの都市が地続きになった **8 km × 6 km** の3Dサバイバルゲームです。街並みは約8.2万棟の建物からなり、200 m四方の1,200区画を現在地の周りから読み込みます。

## 遊び方

1. 道路に落ちている80冊の本（東京に30冊、ほかの5都市に10冊ずつ）のうち、10冊を拾います。徒歩で近づくと自動で拾います。
2. 東京タワーの広場にある赤い鳥居をくぐると、追ってくるものがすべて成仏します。14秒の間に広場の外へ退避してください。
3. 巨大ジェット8基で広場ごと700 mまで上昇します。上昇を終えると、地盤の下から展開した砲台が追尾ミサイル「ゲルニカ」を10秒ごとに発射します。攻撃フェーズを10分間生き延びるとクリアです。
4. 耐久力は4目盛りです。徒歩で直撃を受けると2目盛り減り、車内では車が大破して1目盛り減ります。

徒歩はWASD、スマホは左のスティックで移動します。Shiftまたは「走る」でダッシュし、画面をドラッグして見回します。F・スペース・クリック・右ボタン（スマホは「撃つ」ボタン）で射撃、Rでリロードします。車は近くにある駐車車両にVまたは「車に乗る」で乗れます。W・Sで加速・後退、A・Dで操舵、Shiftでブレーキです。停車すると降車できます。

地下鉄は駅入口を見つけて「地下鉄へ」「列車を呼ぶ」「列車に乗る」と進みます。約15 kmの環状線は7つの駅を結びます。空港の展望デッキでは旅客機の離陸を見られます。道路トンネルも車や徒歩で通れます。

## 追ってくるもの

ゲームを始めるたびに、次の13体が道路上のランダムな地点（1,023か所の候補）に配置されます。およそ半数は出発地の東京、残りは世界のどこかに現れます。

| 種類 | 数 | 見つける距離 | 走る速さ |
| --- | --- | --- | --- |
| 追跡者（小） | 5体 | 140 m | 24 m/s |
| 巨人（大） | 2体 | 176 m | 39 m/s |
| 虚ろ面（ひび割れた白磁の面） | 2体 | 150 m | 13.5 m/s |
| 髑髏面（眼窩に熾火が灯る頭骨） | 2体 | 165 m | 21 m/s |
| 般若面（角と牙のある朱塗りの面） | 2体 | 190 m | 17 m/s |

追跡者と巨人の視認距離は従来の2倍、走る速さは1.3倍です。顔面は高さ4〜5 mで、路上を浮かんで移動します。

どれも視界だけに頼りません。プレイヤーは約3.5 mごとに痕跡を残し、痕跡は75秒残ります。壁越しでも一定距離（44〜84 m）に入ると気配を感じ取り、痕跡に近づいた個体は新しい痕跡へ順にたどります。たどっている間は全速の半分で進み、姿を見つけると全速で追ってきます。見失うと、最後に見た地点の痕跡から追跡を続けます。画面には「痕跡をたどられています」「追跡されています」と表示されます。

## 拳銃 RD II

プレイヤーは三連装の9 mm拳銃「RD II」を持っています。

- 引き金1回で3発を同時に発射します。押し続けると0.19秒ごとに連射します。
- 弾は初速375 m/sで飛び、重力（9.81 m/s²）と速度の2乗に比例する空気抵抗を受けます。減速は銃口で約241 m/s²、100 m先での速度は約314 m/s、落下は約43 cmです。建物・地形・敵との当たりは弾道に沿って判定します。
- 装填数は120発、初期の所持弾は250発（装填120＋予備130）です。撃ち切ると自動でリロードします（1.7秒）。
- 本を集めている間、弾薬箱が約15〜21秒ごとにプレイヤーの近く（4.5〜12 m）へ落ちてきます。拾うと1個で15発増えます。地面に残るのは3個までです。
- 1体に20発命中させると、その敵は3分間気絶します。命中のたびに照準の下に「命中 n / 20」と出ます。撃たれた敵は撃った位置に気づきます。気絶中の敵は動かず、捕まえてきません。顔面は当たるたびにひびが広がって光ります。

## 街と建物

集合住宅の階高は3.77〜4.05 mです。集合住宅と高層ビルは間口と奥行きを広げ、高さと面積に応じた敷地と基礎を持ちます。高層ビルのロビーの床や壁には当たり判定があります。東京タワーは従来モデルの高さ・幅・奥行きの5倍です。

街路沿いの建物は104種類です。従来の44種類に、基壇＋塔、双棟と渡り廊下、L字、段状（ジッグラト）、円筒、張り出し、隅塔、控え壁、門型、群棟の10の形と、ドーム、ヴォールト、尖塔、重ね軒、王冠、給水タンク、屋上庭園、太陽光パネル、ヘリポート、アンテナ塔、屋上看板の11の屋根を組み合わせた60種類を加えました。超高層ビルは螺旋、鐘楼、三脚、階段状、レンズ、多層塔、モノリス、結晶、束ね筒、灯台の10種類を加え、各2棟ずつ計20棟を建てて48棟にしました。

漆喰の塗り直し、石造外壁の修復、タイルや金属板への張り替えなどで、外観と経年劣化が変わります。傷みは16種類（細かなひび、構造ひび割れ、剥落、塗装のめくれ、錆だれ、白華、苔、路面の汚れ、雨だれ、巨人の爪痕、補修跡、落書き、日焼け、欠け、鳥の糞、蔦）あり、建物ごとに各0〜3段階の組み合わせが決まります。年代6 × 色調48 × 劣化度8 × 窓割り8 × 改修10 × 傷みの系統32で外観は約590万通り、建物の種類と高さを掛けると約1,300億通りです。傷みの位置は壁ごとに変わります。180棟の集合住宅では、低層階の窓越しに家具やカーテンが見えます。間取りと内装の配色は棟と窓ごとに生成されます。

幹線道路、中道、小道、砂利道、砂道を整備しました。生成する敷地は、前面から道路へ続く通路を確保できる場所を使います。各都市にはコンビニ、ショッピングセンター、駐車場、公園、建設中の高層ビルがあります。100人の歩行者が街路を巡回します。

屋外は常に昼です。レンガ、石材、コンクリート、木、金属、砂利など29種類の素材に、実寸に合わせた模様と凹凸があります。水面は岸の高さに沿って生成し、遠くの海と空は視線の方向に合わせて描画します。

区画は近い順に読み込みます。描画品質の「自動」は動作速度に合わせて解像度を調整します。Cloudflare版では徒歩・車の移動、列車の呼び出しと乗降、追跡・本の回収・ミサイルの飛行とダメージをサーバーで処理します。

## グラフィック

描画はWebGL 2のリニアHDRパイプラインです。素材や模型のダウンロードを増やさず、すべてシェーダーと実行時の生成で描きます。

- **空と大気**: レイリー散乱・ミー散乱・オゾンを積分した物理ベースの空を、太陽や霞が変わるたびにGPUで表に焼きます。積雲の層は地上に動く雲の影を落とし、遠景は大気遠近法で霞みます。
- **ライティング**: GGXの物理ベース反射、空と地面・建物からの照り返し、2段のカスケードシャドウ（接地点ほど鋭く、離れるほど柔らかい影）、画面空間アンビエントオクルージョン。
- **ポストプロセス**: テンポラルアンチエイリアス、ブルーム、ACESトーンマッピング、色調補正、太陽のグレア、フィルムグレイン。
- **建物と内装**: 窓ごとに奥行きのある部屋をレイで描きます。床・天井・壁・家具・カーテンやブラインド、オフィスの照明、窓から差し込む日だまりが視線に合わせて見えます。ガラスはフレネル反射で空と街並みを映します。
- **顔面と拳銃**: 3種の顔面は符号付き距離関数から生成した約1.2万頂点のメッシュです。釉薬の貫入と黒い涙の跡、頭骨の縫合線と染み、欠けた朱漆と金箔を画素単位で描き、顎が開閉し、目が内側から光ります。RD IIは3本の銃身、ドラム弾倉、照星の発光、刻印を持ち、毎フレーム視点に追従します。
- **人物と車**: 歩行者、追跡者、巨人は符号付き距離関数から生成した滑らかな人体メッシュで、歩き・走りの骨格アニメーションをGPUで計算します。顔、髪、服の縫い目や襟、靴まで描き分けます。車はクリアコート塗装、ガラス、回転するアルミホイールを持つ専用メッシュです。メッシュはWeb Workerで起動時に生成します。
- **自然**: 樹冠は葉の塊ごとに凹凸と隙間を持ち、逆光で透けて風に揺れます。水面と海は波と空の反射、太陽のきらめきを描きます。

設定の「描画品質」は次のとおりです。**自動**はフレーム時間に合わせて解像度を下げ、スマートフォンではアンビエントオクルージョンを省きます。**高精細**はすべての効果を高い解像度で描きます。**軽量**は縦400ピクセルで描いて拡大し、フレームレートの上限を120 fpsにします（実際の値は画面のリフレッシュレートまで）。描くのはプレイヤーから半径50 m以内で、視線の向いている側だけです。それより遠い物や背後の物は頂点の段階で捨て、境目は空の色へ溶かします。影・時間方向のアンチエイリアス・室内表現・雲の影・細かな傷みも省き、FXAAで仕上げます。浮動小数点の描画先を使えない端末では8ビットの描画先に自動で切り替え、WebGL 2自体を使えない場合は従来どおりソフトウェア描画になります。

## 自分のCloudflareにデプロイする

1. このリポジトリをクローンするか、配布用ZIPを展開し、`package.json` があるフォルダを開きます。Node.js 22または24のLTS版を使用してください。
2. 次のコマンドを実行し、ブラウザの認証画面でデプロイ先のCloudflareアカウントを選択します。

```sh
npm ci
npm run build
npx wrangler login
npm run deploy
```

3. Wranglerが表示する `https://…workers.dev` を開きます。画面右上に **Cloudflare 接続済み** と表示されれば、サーバー処理が有効です。初めてWorkersを使うアカウントでは、案内に沿って `workers.dev` サブドメインを設定します。

`npm run build` はワールド区画、衝突・遮蔽データ、素材を生成します。配布用ZIPにはこれらの生成済みデータが入っています。

Worker名は `wrangler.toml` の `name` で変更できます。すでに同名の別プロジェクトがある場合は、初回デプロイ前に変更してください。SQLite Durable Objectは初回デプロイ時のマイグレーションで用意されます。データベースやストレージの個別作成、ゲーム用APIキーの発行は不要です。

`/api/health` を開くと `service: "atlantis"`、`world: "atlas-14"`、`protocol: 4` を確認できます。Cloudflare側の設定と利用枠は各アカウントに適用されます。 [Workersの制限](https://developers.cloudflare.com/workers/platform/limits/) · [Durable Objectsの利用枠](https://developers.cloudflare.com/durable-objects/platform/limits/)

## 処理の分担

| 処理 | 実行場所 |
| --- | --- |
| 加速・減速、歩行・走行、衝突、重力、斜面と水域、橋、地区境界 | Durable Object。最大60 Hz相当の刻みで再計算し、サーバーの経過時間で入力時間を制限 |
| 追跡、痕跡、遮蔽物、本と鳥居、東京タワーの離陸、ミサイル、車両のダメージ | Durable Object。確定結果をWebSocketで返送 |
| 射撃とリロード、弾道、命中と気絶、弾薬箱の落下と回収 | Durable Object。引き金とリロードの操作だけを端末から送信 |
| 現在地、耐久力、本の回収状況、ミッションの一時保存 | セッションごとのSQLite |
| 3D区画の配信 | Workers Static Assets。周辺区画を端末が取得し、移動に合わせて先読み |
| 3D映像、タッチ入力、応答を待つ間の移動予測、照明や噴射炎・煙の描画、発砲音などの効果音の合成 | ブラウザ。移動予測はサーバーの確定結果で補正 |

移動中は操作を約100 msごとにまとめて送信します。停止中も敵やミサイルが動くよう、プレイ画面を開いている間は約100 msごとに進行を同期します。タイトルや設定を開くと、プレイ時間が一時停止します。

クラウド版は1ブラウザにつき1つの匿名セッションです。同じサイトとブラウザで再訪するとゲームが復元されます。プレビュー版の端末内データとは保存先が異なります。新しいタブでゲームを開くと、先に開いていたタブの操作接続が閉じます。

## ローカル確認とマップの再生成

```sh
npm ci
npm run build
npm run dev:cloud
```

テストは開発サーバーと別のターミナルで実行できます。

```sh
npm test
npm run test:cloud
```

`dev:cloud` はWranglerのローカル実行です。通常は `http://localhost:8787` で確認できます。クラウド統合テストはバンドルをdry runで生成し、ローカルのworkerdとテスト専用SQLiteで接続、移動、本の回収、再起動後の復元を確認します。

街路やマップを編集するときは `tools/layout.mjs`、`tools/build-world.mjs`、`dist/geography.js` を参照してください。地図データを公開済みの版から変更する場合は、地図のキャッシュを切り替えるため `WORLD_VERSION` と `dist/_headers` の区画パスを合わせて更新し、`npm run build:world` を実行してからデプロイします。

素材の模様は `tools/build-materials.mjs` で編集できます。変更後は `npm run build:materials` で配信用データを生成します。
