# ATLANTIS v19 — Cloudflare Workers 版

6つの都市が地続きになった **8 km × 6 km** の3Dサバイバルゲームです。各都市の周辺は海に囲まれ、200 m四方の1,200区画を現在地の周りから読み込みます。

## 遊び方

1. 道路に落ちている80冊の本（東京に30冊、ほかの5都市に10冊ずつ）のうち、10冊を拾います。徒歩で近づくと自動で拾います。
2. 東京タワーの広場にある赤い鳥居をくぐると、追ってくるものがすべて成仏します。14秒の間に広場の外へ退避してください。
3. 巨大ジェット8基で広場ごと700 mまで上昇します。上昇を終えると、地盤の下から展開した砲台が追尾ミサイル「ゲルニカ」を10秒ごとに発射します。攻撃フェーズを10分間生き延びるとクリアです。
4. 耐久力は4目盛りです。徒歩で直撃を受けると2目盛り減り、車内では車が大破して1目盛り減ります。

徒歩はWASD、スマホは左のスティックで移動します（歩き毎秒9 m、走り毎秒21 m）。海や川にも入れます。浅い所は川底を歩き、深い所では頭を水面に出して半分以下の速さで泳ぎます（車と追跡者は水に入れません）。プレイヤーは半径0.3 m・高さ1.75 mの体として判定し、0.36 m以下の段は上がれ、頭より上の看板やひさしの下はくぐれます。一人称でも自分の体（胴・腕・脚）が見え、地面に影が落ちます。Shiftまたは「走る」でダッシュし、画面をドラッグして見回します。F・スペース・クリック・右ボタン（スマホは「撃つ」ボタン）で射撃、Rでリロードまたはインクを補充します。Qまたは残弾欄の武器名を押すと武器を切り替えます。車は近くにある駐車車両にVまたは「車に乗る」で乗れます。W・Sで加速・後退、A・Dで操舵、Shiftでブレーキです。停車すると降車できます。

コンパスには次の目標（いちばん近い本、10冊集めた後は鳥居）の方向と距離が表示されます。PCでは E で地下鉄などの操作、M で消音、Esc で設定を開きます（F・スペースは射撃）。設定の「マウスで見回す」をオンにすると、クリックでカーソルを固定してドラッグせずに見回せます。ゲームパッド（標準配置）にも対応しています。左スティックで移動・操舵、右スティックで視点、Aで走る・ブレーキ、Bで乗降、Xで地下鉄などの操作、RTで射撃、Yでリロード、LBで武器切り替え、スタートで設定です。

地下鉄は駅入口を見つけて「地下鉄へ」「列車を呼ぶ」「列車に乗る」と進みます。約15 kmの環状線は7つの駅を結びます。空港の展望デッキでは旅客機の離陸を見られます。道路トンネルも車や徒歩で通れます。

## 追ってくるもの

ゲームを始めるたびに、次の13体が道路上のランダムな地点（1,023か所の候補）に配置されます。およそ半数は出発地の東京、残りは世界のどこかに現れます。

| 種類 | 数 | 見つける距離 | 走る速さ |
| --- | --- | --- | --- |
| 追跡者（小） | 5体 | 140 m | 24 m/s |
| 巨人（大） | 2体 | 176 m | 39 m/s |
| 虚ろ面（ひび割れた白磁の面） | 2体 | 150 m | 13.5 m/s |
| 髑髏面（眼窩に熾火が灯る頭骨） | 2体 | 165 m | 21 m/s |
| 般若面（角と牙のある朱塗りの面） | 2体 | 190 m | 17 m/s |

追跡者と巨人の視認距離は従来の2倍、走る速さは1.3倍です。顔面は高さ4〜5 mで、路上を浮かんで移動します。

どれも視界だけに頼りません。プレイヤーは約3.5 mごとに痕跡を残し、痕跡は75秒残ります。壁越しでも一定距離（44〜84 m）に入ると気配を感じ取り、痕跡に近づいた個体は新しい痕跡へ順にたどります。たどっている間は全速の半分で進み、姿を見つけると全速で追ってきます。見失うと、最後に見た地点の痕跡から追跡を続けます。画面には「痕跡をたどられています」「追跡されています」と表示されます。

## 拳銃 RD II

プレイヤーは三連装の9 mm拳銃「RD II」を持っています。

- 引き金1回で3発を同時に発射します。押し続けると0.19秒ごとに連射します。
- 弾は初速375 m/sで飛び、重力（9.81 m/s²）と速度の2乗に比例する空気抵抗を受けます。減速は銃口で約241 m/s²、100 m先での速度は約314 m/s、落下は約43 cmです。建物・地形・敵との当たりは弾道に沿って判定します。
- 装填数は120発、初期の所持弾は250発（装填120＋予備130）です。撃ち切ると自動でリロードします（1.7秒）。
- 本を集めている間、弾薬箱が約15〜21秒ごとにプレイヤーの近く（4.5〜12 m）へ落ちてきます。拾うと1個で15発増えます。地面に残るのは3個までです。
- 1体に20発命中させると、その敵は3分間気絶します。命中のたびに照準の下に「命中 n / 20」と出ます。撃たれた敵は撃った位置に気づきます。気絶中の敵は動かず、捕まえてきません。顔面は当たるたびにひびが広がって光ります。

## インク武器

インクタンクは最大100.0で、3種類の武器が共有します。Rで補充でき、弾が尽きると自動で補充が始まります。

| 武器 | 発射間隔 | 1発のインク | 攻撃力 | 特徴 |
| --- | --- | --- | --- | --- |
| SR1T | 0.5秒 | 0.8 | 0.9倍 | プレイヤー専用。装填5発。32 m以内かつ赤い四角に入った追跡者を自動でロックし、弾が短時間追尾する |
| H1 | 0.2秒 | 3.0 | 通常 | 1発ずつ連射し、着弾地点の周囲を広く塗る。2体の追跡者も使用する |
| シールダー01 | 0.9秒 | 4.0 | 通常 | 弾速が速い単発式。装備中はT1が受ける攻撃を0.8倍にする |

## 島と海

6地区が海に囲まれた島になりました。商業施設、住居、高層ビル、街灯やベンチなどの小物はマップに配置されません。地区間の道路、東京タワーの発射広場、鳥居、地下鉄、空港の滑走路、緑地への移動地点を利用できます。

外洋の200 m区画は2枚の三角形で描画します。水面は単純な色と波で表示し、海でも泳げます。

## グラフィック

描画はWebGL 2のリニアHDRパイプラインです。素材や模型のダウンロードを増やさず、すべてシェーダーと実行時の生成で描きます。

- **空と大気**: レイリー散乱・ミー散乱・オゾンを積分した物理ベースの空を、太陽や霞が変わるたびにGPUで表に焼きます。積雲の層は地上に動く雲の影を落とし、遠景は大気遠近法で霞みます。
- **ライティング**: GGXの物理ベース反射、空と地面・建物からの照り返し、2段のカスケードシャドウ（接地点ほど鋭く、離れるほど柔らかい影）、画面空間アンビエントオクルージョン。
- **ポストプロセス**: テンポラルアンチエイリアス、ブルーム、ACESトーンマッピング、色調補正、太陽のグレア、フィルムグレイン。
- **地下鉄**: 車体や床、側壁などを平面で組み、開いたドアだけは実際に通れる形にしています。窓・車輪・座席・照明・線路などは専用の画像で描画できます。
- **顔面と拳銃**: 3種の顔面は符号付き距離関数から生成した約1.2万頂点のメッシュです。釉薬の貫入と黒い涙の跡、頭骨の縫合線と染み、欠けた朱漆と金箔を画素単位で描き、顎が開閉し、目が内側から光ります。RD IIは3本の銃身、ドラム弾倉、照星の発光、刻印を持ち、毎フレーム視点に追従します。
- **人物と車**: 歩行者、追跡者、巨人は符号付き距離関数から生成した滑らかな人体メッシュで、歩き・走りの骨格アニメーションをGPUで計算します。顔、髪、服の縫い目や襟、靴まで描き分けます。車はクリアコート塗装、ガラス、回転するアルミホイールを持つ専用メッシュです。メッシュはWeb Workerで起動時に生成します。
- **自然**: 樹冠は葉の塊ごとに凹凸と隙間を持ち、逆光で透けて風に揺れます。水面と海は低負荷の色と波で描きます。上空では鳥の群れが旋回し、地面に影を落とします。
- **動きと光**: 爆発や発射時のエンジンの光が周囲を照らします。運転中の車はブレーキランプ・バックランプが点き、前輪が切れ、加減速やカーブで車体が沈み込みます。近くの歩行者はプレイヤーの方へ顔を向けて道を空け、まばたきもします。一人称視点でも自分の影が地面に映ります。
- **カメラ**: 明るさに目が慣れるような自動露出、速く移動したときのモーションブラー、速度に応じて広がる視野角、爆発や巨人の足音による画面の揺れ。ハイライトのちらつきは法線の変化から抑えます。

効果音もすべてWeb Audioで合成しています。街のざわめきと風、足音、車のエンジンとロードノイズ、ゲルニカの飛来音、距離に応じて遅れて届く爆発音、本を拾う音などが鳴ります。

解像度はFHD（縦1080）・1.5K（縦1200）・2K（縦1440）・4K（縦2160）から選べます。フレームレートの上限は30・60・90・120 FPS・無制限です。影・HDR・反射は個別に切り替えられます。浮動小数点の描画先を使えない端末では8ビット描画に切り替わります。

## 画像生成テクスチャ

`gpt-image-2.5-sunburst`（正方形1:1、モデルが受け付ける最大の解像度、品質 medium）で、1枚の画像に3×3の9種類のテクスチャを生成してゲームに組み込めます。`tools/texture-catalog.json` に10枚分・90種類（これまで手続き生成だけだった素材36種類と、ビルの外観・屋根・街路など54種類）のプロンプトと、使う素材・実寸・色の扱いを定義しています。

```sh
python3 .claude/skills/gpt-image-textures/generate.py --dry-run
OPENAI_API_KEY=... python3 .claude/skills/gpt-image-textures/generate.py
```

通常素材19枚・171タイルに地下鉄用3枚・27タイルを加え、合計22枚・198タイルを収録しています。街路、外壁、屋根、レンガとタイル、ATLANTISらしい石壁・海・聖堂・礼拝堂、街の細部、植物と地面、道路と屋上、室内に加え、人物（服・肌・髪・靴）、車（塗装・タイヤ・シート・内装・メッキ・ライト）、電車と旅客機、東京タワーと鳥居と発射台、線路・地下鉄トンネル・滑走路・街灯・ガードレール・マンホール、ガラス、煙・炎・砂ぼこり・火花、水面のさざ波まで写真の質感になります。樹皮は木の幹に、点字ブロックとタイル床は地下鉄のホームに、畳・カーペット・フローリング・壁紙・天井板は室内に貼られます。

生成した画像は各マスを切り出して継ぎ目のないタイルにし、`dist/materials/generated/` にWebPのアトラスと `manifest.json` として書き出します。ゲームは起動時にこれを読み込み、素材ごとに最大8種類のテクスチャから建物ごとに1つを選んで貼ります（ビル全体で同じものを使います）。生成前や読み込めない端末では、これまでの手続き生成の質感のまま動きます。APIキーはリポジトリに保存しないでください。手順の詳細は `.claude/skills/gpt-image-textures/SKILL.md` にあります。

地下鉄は `dist/materials/generated/` の3×3シートを使用します。`metro-train.webp` と `metro-train-worn.webp` は車両ごとの外観と内装、`metro-station.webp` は駅とトンネルの9素材です。各タイルの対応先は `dist/metro-materials.js` にあります。

## 自分のCloudflareにデプロイする

1. このリポジトリをクローンするか、配布用ZIPを展開し、`package.json` があるフォルダを開きます。Node.js 22または24のLTS版を使用してください。
2. 次のコマンドを実行し、ブラウザの認証画面でデプロイ先のCloudflareアカウントを選択します。

```sh
npm ci
npx wrangler login
npm run deploy
```

3. Wranglerが表示する `https://…workers.dev` を開きます。画面右上に **Cloudflare 接続済み** と表示されれば、サーバー処理が有効です。初めてWorkersを使うアカウントでは、案内に沿って `workers.dev` サブドメインを設定します。

Wranglerは公開前に `npm run build` を実行し、ワールド区画、衝突・遮蔽データ、素材を生成します。Workers Buildsで自動公開する場合は、本番ブランチを `main`、デプロイコマンドを `npx wrangler deploy` に設定します。配布用ZIPにはこれらの生成済みデータが入っています。

Worker名は `wrangler.toml` の `name` で変更できます。すでに同名の別プロジェクトがある場合は、初回デプロイ前に変更してください。SQLite Durable Objectは初回デプロイ時のマイグレーションで用意されます。データベースやストレージの個別作成、ゲーム用APIキーの発行は不要です。

`/api/health` を開くと `service: "atlantis"`、`world: "atlas-16"`、`protocol: 4` を確認できます。Cloudflare側の設定と利用枠は各アカウントに適用されます。 [Workersの制限](https://developers.cloudflare.com/workers/platform/limits/) · [Durable Objectsの利用枠](https://developers.cloudflare.com/durable-objects/platform/limits/)

## 処理の分担

| 処理 | 実行場所 |
| --- | --- |
| 加速・減速、歩行・走行、衝突、重力、斜面と水域、橋、地区境界 | Durable Object。最大60 Hz相当の刻みで再計算し、サーバーの経過時間で入力時間を制限 |
| 追跡、痕跡、遮蔽物、本と鳥居、東京タワーの離陸、ミサイル、車両のダメージ | Durable Object。確定結果をWebSocketで返送 |
| 射撃とリロード、弾道、命中と気絶、弾薬箱の落下と回収 | Durable Object。引き金とリロードの操作だけを端末から送信 |
| 現在地、耐久力、本の回収状況、ミッションの一時保存 | セッションごとのSQLite |
| 3D区画の配信 | Workers Static Assets。周辺区画を端末が取得し、移動に合わせて先読み |
| 3D映像、タッチ入力、応答を待つ間の移動予測、照明や噴射炎・煙の描画、発砲音などの効果音の合成 | ブラウザ。移動予測はサーバーの確定結果で補正 |

移動中は操作を約100 msごとにまとめて送信します。停止中も敵やミサイルが動くよう、プレイ画面を開いている間は約100 msごとに進行を同期します。タイトルや設定を開くと、プレイ時間が一時停止します。

クラウド版は1ブラウザにつき1つの匿名セッションです。同じサイトとブラウザで再訪するとゲームが復元されます。プレビュー版の端末内データとは保存先が異なります。新しいタブでゲームを開くと、先に開いていたタブの操作接続が閉じます。

## ローカル確認とマップの再生成

```sh
npm ci
npm run dev:cloud
```

テストは開発サーバーと別のターミナルで実行できます。

```sh
npm test
npm run test:cloud
```

`dev:cloud` はWranglerのローカル実行です。通常は `http://localhost:8787` で確認できます。クラウド統合テストはバンドルをdry runで生成し、ローカルのworkerdとテスト専用SQLiteで接続、移動、本の回収、再起動後の復元を確認します。

街路やマップを編集するときは `tools/layout.mjs`、`tools/build-world.mjs`、`dist/geography.js` を参照してください。地図データを公開済みの版から変更する場合は、地図のキャッシュを切り替えるため `WORLD_VERSION` と `dist/_headers` の区画パスを合わせて更新し、`npm run build:world` を実行してからデプロイします。

素材の模様は `tools/build-materials.mjs` で編集できます。変更後は `npm run build:materials` で配信用データを生成します。

## GitHub Pagesで公開する

GitHub Pagesの公開元が「ブランチ（`main` の直下）」のままだと、ゲーム本体の `dist/` もワールドデータも公開されず、README.mdがトップページとして表示されます。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
2. **Actions** タブで **Deploy to GitHub Pages** を実行します。以後は `main` に反映するたびに `.github/workflows/pages.yml` がワールドデータを生成し、テストを通してから `dist/` を公開します。

GitHub Pages版はサーバー処理のない「ブラウザ版」として動き、進行状況はブラウザに保存されます。なお、GitHubのリポジトリ画面でファイル一覧の下にREADME.mdが表示されるのはGitHubの標準の動作です。
