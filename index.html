ゲーム本体は dist/ にあります

このページが見えているときは、GitHub Pagesがリポジトリの直下をそのまま公開しています。ゲームの公開には、ワールドデータを生成するビルドが必要です。

  1. リポジトリの Settings → Pages を開きます。
  2. Build and deployment の Source を GitHub Actions にします。
  3. Actions タブで Deploy to GitHub Pages を実行します。以後は main への反映ごとに自動で公開されます。

GitHub Pages版はブラウザ内で動く「ブラウザ版」です。サーバー処理を含む完全版はCloudflare Workersにデプロイします（README参照）。
